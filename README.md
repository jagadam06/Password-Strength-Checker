# 🔐 Password Strength Checker

A Python-based web application that checks password strength and helps users create secure passwords.

## ✨ Features
- Checks password strength.
- Evaluates password length.
- Checks uppercase and lowercase letters.
- Checks numbers and special characters.
- Displays password strength feedback.

## 🛠️ Technologies Used
- Python
- HTML
- CSS
- JavaScript
- Flask

## 📂 Project Structure
- `app.py` – Python backend
- `index.html` – Webpage structure
- `style.css` – Styling
- `script.js` – Password checking functionality
- `test.py` – Testing
- `requirements.txt` – Required Python packages

## 🚀 How to Run

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open the local URL displayed in the terminal.

## 🎯 Objective
To encourage users to create strong passwords and improve password security.
